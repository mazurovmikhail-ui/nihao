# Нихао: китайский с нуля

**→ https://mazurovmikhail-ui.github.io/nihao/**

Бесплатное приложение для русскоязычных, которые начинают китайский. Без рекламы,
без регистрации, без интернета. Прогресс хранится в телефоне.

Открыть ссылку на телефоне → меню браузера → «Установить приложение» или «На главный
экран». Дальше запускается с иконки и работает офлайн. Android-сборка для RuStore и
Google Play собирается из тех же файлов (см. ниже).

## Что внутри

- **Курс.** 150 слов уровня HSK 1 в 16 уроках по темам. У каждого урока короткая
  заметка по грамматике на русском, у каждого слова пример с переводом.
- **Тоны.** Отдельный вводный урок с озвучкой и цветовая разметка тонов в пиньине
  во всём приложении. Упражнение «Какой тон?» тренирует слух.
- **Упражнения.** Перевод в обе стороны, распознавание на слух, ввод пиньиня, сбор
  фразы из слов. Верный ответ листается сам, ошибка возвращает слово в конец сессии.
- **Интервальное повторение.** Каждое слово живёт по своему графику (SM-2): чем лучше
  помните, тем реже спрашивает. На главном экране видно, сколько слов подошло к сроку.
- **Серия дней.** Засчитывается за одну короткую сессию, отдельно от цели по очкам,
  чтобы серию было легко держать.
- **Словарь и ключи.** Поиск по иероглифу, пиньиню и переводу, 20 ключей иероглифов.
  При наличии сети открываются прописи с порядком черт и проверкой написания.

## Чем отличается от аналогов

Duolingo умеет возвращать пользователя, но слабо учит именно китайскому: без тонов и
объяснений грамматики. HelloChinese учит хорошо, но платный и на английском. Здесь
собраны обе стороны для русскоязычного: механика привычки и содержание про тоны и
грамматику, на русском и бесплатно.

## Как устроено

Веб-приложение без сборки: `index.html`, `styles.css`, `app.js`, `data.js` (весь курс),
`sw.js` (офлайн-кэш). Озвучка голосом системы (Web Speech API), китайский голос ставится
в настройках телефона. Прописи подгружают библиотеку hanzi-writer из сети.

Приложение для магазинов собирается через Capacitor в GitHub Actions
(`.github/workflows/android.yml`): после каждого пуша в `main` появляется артефакт
`nihao-debug-apk`; с ключом подписи в секретах репозитория собирается `nihao-release-aab`.

## Как помочь

Ошибки в словах и переводах, идеи упражнений, новые уроки: через issues или pull request.
Курс лежит в `data.js` в простом формате, править можно без программирования.
